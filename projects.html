Execution Risk Manager

In Development

A risk management layer that wraps all trading bots. Enforces Complete-or-Abort execution logic — if any condition fails mid-execution, the full order sequence rolls back. Handles position sizing relative to available capital, per-trade exposure limits, and full structured logging for post-execution analysis. Designed as a composable module deployable across all AMC Labs strategies.

# risk gate logic
def execute_safe(order):
  with RiskGate(order) as g:
    if not g.size_ok():
      raise Abort()
    if not g.margin_ok():
      raise Abort()
    g.execute()
